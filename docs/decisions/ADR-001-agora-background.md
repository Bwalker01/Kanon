# ADR-001: Agora is background only

## Context

The original brief said Kanon supersedes an idea "first dubbed agora". Revision 1 of the
foundation plan found no repository for it and asked where it was.

## Decision

Agora was an idea, not a repository. It is background only. Kanon takes no requirements
from it beyond what the owner's brief states.

## Evidence

- Owner answer 1 ([owner brief](../sources/2026-11-13-owner-brief.md), section 2).
- Search on 2026-11-13 found no Agora repository under `Bwalker01` or `antikas`.

## Consequences

- Nothing in Kanon has to be traced back to Agora.
- If an Agora document turns up later, it goes into `docs/sources/` and is compiled like
  any other source.

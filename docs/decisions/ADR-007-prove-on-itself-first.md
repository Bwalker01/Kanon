# ADR-007: Prove Kanon on itself first

## Context

Revision 1 asked whether there was a real project to test Kanon on in Phase 1.

## Decision

There is no outside project yet. Kanon is proven on its own repository first: from
Phase 1, Kanon is planned, reviewed, approved and documented with Kanon. An outside project
comes in Phase 5.

## Evidence

- Owner answer 7.

## Consequences

- This repository already follows the Kanon layout (Phase 0).
- Every phase's "done when" is demonstrated in this repository.
